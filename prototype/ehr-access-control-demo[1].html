Environment and architecture

This initial prototype uses one local HTML file, plain JavaScript, and embedded synthetic JSON data. A browser runs the code. No framework, package installation, database connection, or live EHR is required.

The interface collects the request. A separate policy function checks identity, role, context, risk, and emergency conditions. The result drives the resource display, and an audit function records the event.

Browser-side enforcement, authentication, alerts, and account states are educational simulations. Production server-side controls, real MFA, and tamper-resistant audit storage are outside this initial demonstration.

Run synthetic acceptance tests

36 role tests across six roles, plus 6 emergency tests. These compare expected and actual decisions; they do not measure hospital performance or certify compliance.
